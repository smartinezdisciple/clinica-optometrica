# Misión

Sistema de gestión integral para la clínica optométrica Dr. Lentes.

Cubrir ventas (POS), compras, citas, pacientes, empleados, inventario, sucursales y expedientes clínicos en una sola plataforma web moderna.

## Prioridades de diseño

- **Facilidad de uso:** interfaz intuitiva que minimice la curva de aprendizaje del personal.
- **Rapidez:** ingreso y búsqueda de pacientes en pocos segundos, sin fricción.
- **Visibilidad en tiempo real:** las operaciones del optometrista deben reflejarse al instante para el vendedor; las del vendedor deben reflejarse al instante para el cajero.
